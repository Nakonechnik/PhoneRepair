# Phone Repair — заявка на ремонт смартфона

**ФИО:** УКАЖИТЕ_ФИО  
**Группа:** УКАЖИТЕ_ГРУППУ

## Предметная область

Приложение моделирует одну заявку в сервисном центре по ремонту смартфона. У заявки есть состояния: новая, диагностика, ожидание запчастей, ремонт, готов к выдаче, выдан, отклонён. Переходы между ними разрешены только по правилам: например, ремонт нельзя начать, пока одновременно не выполнены диагностика, наличие запчастей, согласие клиента и оплата (либо гарантия). Сложность повреждения влияет на смету и на то, нужны ли запчасти со склада. В особых состояниях экран меняет цвет и показывает предупреждение; после выдачи или отклонения действия блокируются. Заявку можно сбросить в исходное состояние. В следующих заданиях появятся список заявок и история по каждой из них.

## Как запустить

1. Открыть проект в Android Studio.
2. Дождаться синхронизации Gradle.
3. Запустить на эмуляторе или устройстве.
